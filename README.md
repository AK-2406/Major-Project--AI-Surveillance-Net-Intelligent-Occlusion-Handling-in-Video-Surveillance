# Major-Project
Project Name --> AI Surveillance Net: Intelligent Occlusion HAndling in Video Surveillance

## System Overview
The AI SurveillanceNet system is designed to address a critical challenge in modern surveillance systems: the accurate detection and recognition of partially occluded objects, specifically focusing on vehicle identification and license plate recognition. The system architecture employs two specialized deep learning models working in tandem: a YOLOv11-based model for license plate detection and optical character recognition (OCR), and a YOLOv8-based model for vehicle detection and classification. These models are integrated within a cohesive software framework using Python, with Streamlit providing the frontend interface for real-time monitoring and analysis.

The system's primary objective is to maintain high recognition accuracy even when surveillance footage contains partial occlusions, varying lighting conditions, or non-optimal camera angles. This is achieved through a series of methodological innovations in model training, data augmentation, occlusion handling strategies, and system integration.
